# Muzaffargarh City Hub (MZG HUB)

A premier, Awwwards-grade, ultra-smooth digital business directory and storefront platform for Muzaffargarh, Pakistan.

* **Live Demo (GitHub Pages)**: [https://rehantechhub0-boop.github.io/Mzg-Muzaffargarh/](https://rehantechhub0-boop.github.io/Mzg-Muzaffargarh/)
* **Dedicated Storefronts**: [https://rehantechhub0-boop.github.io/Mzg-Muzaffargarh/store.html?id=4](https://rehantechhub0-boop.github.io/Mzg-Muzaffargarh/store.html?id=4)

---

## Features
* **60fps Procedural 3D Canvas Hero**: Scroll-driven kinetic 3D engine with gyroscope orbital rings, warp city constellation, and luminous horizon glow synced via GSAP ScrollTrigger and Lenis smooth scrolling.
* **Compact 2-Column Mobile Grid**: App-like mobile experience with zero cropping on 360px–430px screens.
* **Verified District Directory**: Verified business cards with direct WhatsApp connect, Google Maps links, and 3D perspective spotlight effects.
* **Dedicated Merchant Storefronts (`store.html`)**: Complete product catalogs with titles, prices, descriptions, and direct **"Order on WhatsApp"** buttons per item.
* **Zero Build Tools**: Pure semantic HTML5, CSS3, ES6+ Vanilla JavaScript, and Tailwind CSS via CDN.
